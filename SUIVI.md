## Mis de côté

- **GitHub : quelle voie ?** — « met de coté » (18/11). (A) Le site GitHub appelle l'API qui est déjà sur InfinityFree : un seul serveur et une seule base, le même monde sur les deux sites, peu de travail (autoriser l'autre site dans l'API, régler le cookie de session, et vérifier que la protection anti-robot d'InfinityFree laisse passer les appels d'un autre site, ce qui n'est pas sûr). (B) Un second serveur chez Supabase, comme dans ton exemple : tout le serveur est à réécrire en TypeScript et en SQL Postgres (comptes, monde, base, atelier, missions, alertes, résultats), un travail de plusieurs jours, avec deux serveurs et deux bases séparées à faire évoluer ensemble ; il te faut créer le compte et le projet Supabase toi-même (je ne crée pas de compte), puis poser ses clés comme secrets du dépôt. Je recommande A d'abord ; B plus tard si A est bloquée. L'adresse du site est connue (`ww2.gamer.free`) : je peux tester dans le navigateur si l'anti-robot laisse passer les appels d'un autre site.
